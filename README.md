# Kitab Ghar — Badlapur

Kitab Ghar is a local book-rental and membership platform for readers in Badlapur, Maharashtra. This repository is developed progressively as one business case study across ten Web Lab experiments.

## Current status

Experiments 1–9 are complete: the project contains a responsive Bootstrap registration module, a searchable ES6 catalogue using the supplied 77-title PDF, React component and Router implementations, a validated MongoDB database, an Express/Mongoose API, separate Node.js core demonstrations, a Postman-ready REST API, and a React client connected to the real API for registration, login, books, memberships, rentals, returns and profile updates. Experiment 10 deployment configuration is ready; live hosting credentials and deployment execution remain environment-specific.

## Local demo accounts

These accounts are created by `cd server && npm run seed` for local/demo testing only. Do not use these passwords in a deployed environment.

| Role | Email | Password |
| --- | --- | --- |
| Admin | `admin@kitabghar.local` | `KitabGhar@2026!` |
| Customer | `reader@kitabghar.local` | `Reader@2026!` |

The admin account can open `/admin`; the customer account can browse, subscribe, add books to a rental cart, submit a delivery request and track the request.

## Rental delivery workflow

1. A member adds an available book to `/cart` and confirms their Badlapur address.
2. The request appears in Admin → Orders. Admin chooses home delivery or pickup and moves it through review, packed, out for delivery and delivered.
3. Marking an order delivered creates the active 30-day rental and sends the customer an inbox notification. Return reminders and membership-expiry reminders are generated by the server scheduler.

## Payment verification

Membership checkout supports a UPI QR demo flow. The customer scans the configured UPI ID, submits the transaction reference, and the admin verifies or rejects it from the Admin → Payments queue. A static QR cannot verify bank settlement automatically; connect a gateway webhook and set `UPI_ID` before production launch.
