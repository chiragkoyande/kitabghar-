# Kitab Ghar Web Lab Manuals

Manuals are generated in the requested college format: Times New Roman, 12 pt body text, 14 pt headings, justified paragraphs and 1.5 line spacing.

## Generated Manuals

Old experiment manuals and evidence have been removed. Replacement manuals will be generated from the current main Kitab Ghar implementation after each experiment is rebuilt and tested against its required practical topic.

## Regenerate

```bash
node scripts/manual-agent/run-manual-agent.mjs --experiment 3
```

Each generated manual contains real screenshots captured from the corresponding running implementation. Do not substitute placeholder images for evidence.
