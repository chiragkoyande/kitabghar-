# Experiment 2: ES6 JavaScript Features

This directory contains standalone demonstrations of modern JavaScript (ES6) features implemented for the Kitab Ghar library platform. 

It satisfies the college practical requirements for demonstrating:
- Arrow Functions
- Anonymous Functions
- Arrays (map, filter, reduce)
- Events (click, input, change, mouseover)
- Popup Boxes (alert, confirm, prompt)

## Files Included

1. `index.html` - The main UI containing the 5 required sections using Bootstrap 5.
2. `es6-demo.js` - The vanilla JavaScript file powering the HTML interactions.
3. `es6-node.mjs` - A terminal-based Node.js script demonstrating the exact same concepts.
4. `styles.css` - Custom styling for code blocks and outputs.

## How to Run

### Browser Demonstration (UI)
Simply open `index.html` in your web browser. Each section has interactive buttons demonstrating specific concepts with visible outputs.

### Terminal Demonstration (Node.js)
Run the following command from the project root:
```bash
node experiments/exp2/es6-node.mjs
```

## Concept Details
All data used in these demos revolves around a realistic Kitab Ghar book catalogue to ensure contextual relevance to the main project theme.
